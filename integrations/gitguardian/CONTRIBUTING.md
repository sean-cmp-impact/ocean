# Contributing to Ocean - gitguardian

## Obtaining a GitGuardian API Token

This integration requires a GitGuardian API token. Please see [Creating your API key](https://docs.gitguardian.com/api-docs/authentication#creating-your-api-key) for more details.

## GitGuardian API

This integration uses the [GitGuardian API](https://api.gitguardian.com/docs) to obtain source, secret detector, incident, and user data.
